# Detection and Classification of Soybean Pests Using Deep Learning with UAV Images

## 1. Project Overview
This project aims to develop a deep learning-based system for detecting and classifying soybean pests using images.

## 2. Objectives
- To identify soybean pests from images.
- To classify pests into their respective categories.
- To support early pest identification in precision agriculture.

## 3. Dataset
The project uses a dataset of 6,410 soybean images containing three categories:
- Healthy
- Caterpillar
- Diabrotica speciosa

## 4. Technologies Used
- Python
- Google Colab
- PyTorch
- OpenCV
- NumPy
- Matplotlib

## 5. Project Workflow
1. Dataset Collection and Inspection
2. Data Preparation
3. Image Preprocessing
4. Dataset Splitting
5. Model Selection
6. Model Training
7. Model Evaluation
8. Prediction on New Images

## 6. Expected Output
The system aims to identify soybean pest categories from input images and provide prediction results.
